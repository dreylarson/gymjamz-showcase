# GymJamz
## A gym-focused social music discovery application built with React Native and TypeScript
Status: In development | Platform: Mobile | Repository: Public Showcase (Source Private)

## Project Overview
GymJamz is an independently developed mobile application designed to connect gym-goers through their music preferences and listening activity.

The project explores the intersection of music streaming, fitness communities, and social discovery, with the goal of allowing users to discover what others at their gym are listening to.

From a software engineering perspective, GymJamz serves as a hands-on project for developing and refining skills in React Native, TypeScript, mobile UI architecture, component-based development, and third-party service integration.

The application is currently in active development, with its core interface and listening-feed prototype established. Music-service integration and additional social functionality remain planned features.
