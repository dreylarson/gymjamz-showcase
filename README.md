# GymJamz
## A gym-focused social music discovery application built with React Native and TypeScript
Status: In development | Platform: Mobile | Repository: Public Showcase (Source Private)

## Project Overview
GymJamz is a mobile application designed to connect gym-goers through the music they're listening to during their workouts.

The core concept is simple: open GymJamz at your gym and discover what other members are listening to in real time. Rather than relying solely on algorithms and curated playlists, users can discover new songs, artists, and genres through the live listening activity of people sharing their workout environment.

The experience is designed to be interactive. When users play music through GymJamz, their listening activity will appear in their gym's live feed, allowing other members to discover what they're listening to.

GymJamz aims to transform an otherwise individual experience—listening to music while exercising—into an opportunity for social connection and organic music discovery.

## Development Focus
GymJamz is an independently developed mobile application built using React Native, Expo, and TypeScript.

The project demonstrates practical experience in mobile interface development, component-based architecture, typed data structures, and designing an application around future third-party music-service integration.

The current prototype includes the foundational home screen and gym-based listening feed. Live listening activity, music-service integration, and expanded social functionality remain in development or planned.

This repository serves as a public portfolio showcase. The application's source code is maintained in a private repository.

## Technology Stack
GymJamz is developed using the following technologies:

| Technology | Role in the Project |
|---|---|
| **React Native** | Building the application's cross-platform mobile interface using reusable components. |
| **TypeScript** | Providing static typing for components and application data. |
| **Expo** | Managing the development environment and testing the application. |
| **React Hooks** | Managing component state and lifecycle behavior. |
| **Git & GitHub** | Version control, feature development, and source code management. |

The application follows a component-based development approach, emphasizing maintainability, consistent interface design, and scalability.
